# 0800webs.com

Sitio de [0800](https://0800webs.com/): catálogo de 0800 Commerce y 0800 Content, con el
portfolio de webs andando y demos. HTML estático; el build de Pages (`.github/armar.mjs`)
solo copia y arma `sitemap.xml`.

- `index.html` — la home entera. Lo que se toca seguido está en `CFG`, al final.
- `img/portfolio/` — capturas de 1280×800 achicadas a 960×600.
- Las carpetas de las campañas viejas (rubros, hospedajes, oficios, portal) son
  redirecciones a la home; `404.html` hace lo mismo con todo lo que colgaba de ellas.
